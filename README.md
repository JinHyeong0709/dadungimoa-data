# dadungimoa-data

[다둥이모아](https://github.com/JinHyeong0709/dadungimoa) 앱이 받아 쓰는 가맹점 데이터입니다.
GitHub Pages 로 게시되며, 앱은 실행할 때 `v1/manifest.json` 을 보고 더 새 카드 파일만 받습니다.

**이 저장소는 사람이 고치지 않습니다.** 앱 저장소의 GitHub Actions
(`.github/workflows/data-update.yml`)가 매주 일요일 08:00(KST) 원본을 확인하고,
바뀐 카드만 다시 만들어 검증한 뒤 여기에 올립니다.

| 경로 | 내용 |
|---|---|
| `v1/manifest.json` | 카드별 파일 이름, 생성 시각, 건수, 원본 지문 |
| `v1/seoul.json` | 서울 다둥이 행복카드 협력업체 |
| `v1/busan.json` | 부산 가족사랑카드 참여업체 |
| `cache/` | 주소→좌표 조회 캐시. 새 주소만 조회하려고 보관합니다 |

## 원본과 이용 조건

- 서울 열린데이터광장 「서울시 다둥이 행복카드 협력업체 정보」(제공: 우리카드) — 공공누리 제3유형(출처표시 + 변경금지)
- 공공데이터포털 「부산광역시_가족사랑카드 참여업체 현황」(제공: 부산광역시) — 이용허락범위 제한 없음
- 업체 좌표는 행정안전부 도로명주소 API 로 원본 주소를 변환한 것입니다.

원본의 글자는 바꾸지 않습니다. 좌표와 좌표 정확도(`precision`, `approxRadiusM`)만 덧붙입니다.
